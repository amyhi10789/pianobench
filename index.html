Why PianoBench

Plausible is not the same as correct.

One controlled instrument makes discrete multimodal failures visible, audible, and measurable.

Text-to-video systems can render a convincing pianist while playing the wrong pitch, adding an extra note, missing a key press, or placing the sound before the motion. PianoBench separates these errors instead of hiding them inside one general quality score.

Every prompt pairs a constrained overhead performance with a machine-readable event target. The benchmark then evaluates acoustic content, visible execution, and cross-modal timing independently.

01 35% aggregate weight

Hear the right notes

Measures event count, pitch, order, onset timing, and duration from the generated audio.

02 35% aggregate weight

See the right action

Checks visible note identity, key travel, event order, extra presses, and the one-hand constraint.

03 30% aggregate weight

Match sight to sound

Pairs acoustic onsets with visible press events and scores their temporal agreement.

Prompt suite

Five families. Increasing event complexity.

Each family contains five controlled prompts. Camera, keyboard, hand count, and acoustic setting stay fixed while the requested musical structure changes.

  1. Level 01 · 5 prompts

    Single notes

    Tests isolated pitch identity, a prescribed onset, and a visible half-second hold.

    ExampleC4 @ 3.0 s × 0.5 s
  2. Level 02 · 5 prompts

    Ascending sequences

    Tests whether separate notes appear in the requested increasing order without extras.

    ExampleC4 → D4 → E4 → F4
  3. Level 03 · 5 prompts

    Descending sequences

    Reverses the direction while preserving count and distinct key motion.

    ExampleF4 → E4 → D4 → C4
  4. Level 04 · 5 prompts

    Repeated notes

    Requires complete release and a new visible activation for repeated pitches.

    ExampleC4 → C4 → E4 → C4
  5. Level 05 · 5 prompts

    Chords

    Tests simultaneity within each group and ordering between multiple chord events.

    Example(C4+E4) → (F4+A4)

Evaluation pipeline

Structured targets meet event-level evidence.

Prompt expectations and generated videos feed separate audio and visual analyzers. Detected events are then paired to measure synchronization.

Inputs Prompt + event expectation Pitch, count, order, timing, duration, and chord groups
→
Branch A Audio event analysis
Branch B Visual action analysis
→
Outputs Three interpretable scores Audio accuracy · visual accuracy · AV alignment
0.35 × audio

Acoustic events

Onset detection and pitch estimation score count, pitch class, order, timing, and duration. Chords use a separate multipitch path.

0.35 × visual

Visible actions

Timestamped video frames support structured judgments of note position, press count and order, key travel, extras, and hand count.

0.30 × alignment

Cross-modal timing

Nearest acoustic and visual events are paired. Credit tapers to zero as absolute lag approaches half a second.

Overall = 0.35 · Audio + 0.35 · Visual + 0.30 · AV alignment
Scope and limitations

A diagnostic, not a universal ranking.

PianoBench is intentionally narrow. Its value comes from exposing how a generated performance fails, not from claiming a complete measure of video quality or musicianship.

  • 01
    Each score describes one selected output per prompt and system label; no uncertainty estimate is implied.
  • 02
    The pilot focuses on one instrument, white keys in the middle register, and a constrained overhead view.
  • 03
    Audio analysis is heuristic, while visual scoring depends on sparse frames and a versioned multimodal judge.
  • 04
    Generation versions, seeds, retry decisions, and complete raw generation logs are not yet recorded for every output.
